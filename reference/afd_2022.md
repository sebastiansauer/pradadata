# Party platform ("Grundsatzprogramm") of the AfD party ("Alternative for Germany") as of 2018

This is a dataframe where each row is a page in the AfD party platform.
The document is labelled to having been published in 2018, but I
accessed it in 2022, so that's why it is called afd_2022.

## Usage

``` r
data(afd_2022)
```

## Format

A data frame containing 96 rows and 2 variables

- text:

  Character. Text of the page

- page:

  Integer. Page number

## Source

AfD Deutschland, upload time stamp 2022-10-16,
<https://www.afd.de/___grundsatzprogramm/>
