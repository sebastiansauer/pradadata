# Correlated data

simulated data points for two variables with varying degrees of
correlation

## Usage

``` r
data(corr_data)
```

## Format

A data frame containing 900 rows and 5 columns

- V1:

  Variable 1

- V2:

  Variable 2

- correlationn:

  correlation coefficient (Pearson)

- id_cor:

  id of the correlation (1-9)

- id:

  line number

## Details

The following correlations values are simulated in n=100 data points
each: \#' -0.999999, -0.90, -0.75, -0.30, 0.00, 0.30, 0.75, 0.90,
0.999999. Each value has a different id.
