# Dictionary of German politicians and their party affiliation

This list was curated by Sebastian Sauer in August 2017. Only
politicians with active Twitter accounts were considered. Not all
politicians and not all parties where included to this list. However, it
was tried to include some of the most promiment politicians (provided
they have a Twitter account)

## Usage

``` r
data(polits_twitter)
```

## Format

A data frame containing 200 rows and 2 variables

- party:

  Chr. Short form of the affiliated party

- screenName:

  Chr. Twitter account name of this politician
