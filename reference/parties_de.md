# Names of the parties who ran for the German federal elections 2017

Data is made available for unrestricted use provided the source is
credited.

## Usage

``` r
data(parties_de)
```

## Format

A data frame containing 43 rows and 2 columns

- party_short:

  The short name (acronym) of the party

- party_long:

  The long (spelled-out) name of the party

## Source

This dataset is based on data published by the Bundeswahlleiter 2017,
(c) Der Bundeswahlleiter, Wiesbaden 2017,
<https://www.bundeswahlleiter.de/info/impressum.html>, Data is made
available for unrestricted use provided the source is credited.
