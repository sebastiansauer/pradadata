# Short version of the Ames housing data

This is a shortened version of the Ames housing data, test set

## Usage

``` r
data("ames_de_test")
```

## Format

A data frame containing 500 rows and 11 columns

- id:

  id

- preis:

  price

- wohflaeche:

  size

- grundstuecksflaeche:

  lot size

- badezimmer:

  number of bath rooms

- schlafzimmer:

  number of rooms

- baujahr:

  year built

- garage:

  car garage included?

- kamin:

  Fireplace included?

- umbau:

  Has the house been renovated?

- pool:

  Swimming pool included

## Source

Journal of Statistics Education 19 (3).'
