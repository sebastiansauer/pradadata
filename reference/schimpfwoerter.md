# List of profane words (Schimpfwörter) in German

Schimpfwoerter collection, potentially useful for spam or hate
detection. Attention: explicit content.

## Usage

``` r
data(schimpfwoerter)
```

## Format

A data frame containing 1 variable and approx. 6000 rows

- word:

  Character. Profane word
